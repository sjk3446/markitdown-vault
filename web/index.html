PC LOCAL ENGINE

PC 고급 로컬 엔진 사용하기

웹브라우저 보안상 웹사이트가 Windows 프로그램을 직접 설치할 수는 없습니다. 아래 과정은 최초 한 번만 필요합니다.

  1. 설치 ZIP 다운로드압축 파일이 내려받아지는 것이 정상입니다.
  2. 압축을 완전히 풀기ZIP 안에서 바로 실행하지 마세요.
  3. Install-Windows.cmd 실행설치가 끝나면 바탕화면에 MarkItDown Vault 바로가기가 만들어집니다.
  4. 이후에는 바로가기 실행공개 화면으로 돌아와 ‘PC 엔진 시작·연결’을 누르면 됩니다.

PC 엔진은 외부 서버가 아니라 내 컴퓨터의 127.0.0.1:8787에서만 실행됩니다.
